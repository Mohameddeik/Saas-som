# KulmiyeDataClone (Android)

A minimal Jetpack Compose scaffold that mirrors common telco data top-up flows with bottom navigation. Replace placeholder screens with real features.

## Build

Requirements: JDK 17, Android SDK (compile 34), Gradle Wrapper or local Gradle.

```bash
# From /workspace/android
./gradlew :app:assembleDebug
```

Generated APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Run

Open the `android/` directory in Android Studio and run on an emulator/device.
